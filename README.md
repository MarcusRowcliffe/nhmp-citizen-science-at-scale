Analysis code and outputs for the [NHMP](https://ptes.org/campaigns/hedgehogs/nhmp/) Citizen science at scale: Harnessing AI to launch a national camera-trap network for mammal conservation paper.

To find out more about the National Hedgehog Monitoring Programme (NHMP) please visit https://ptes.org/campaigns/hedgehogs/nhmp/.

The underlying data is not included here but can be made available subject to data sharing agreements by contacting the NHMP team at https://ptes.org/campaigns/hedgehogs/nhmp/. Survey location identifiers have been redacted from the analysis code.
